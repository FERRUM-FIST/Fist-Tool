OPTIMIZATION GUIDE

Learn how to configure GameLoop for solid 120 FPS, apply latency tweaks, and resolve common troubleshooting questions.

CHAPTER 01

Step 1: Create a System Restore Point

Before applying any deep Windows registry or system service tweaks, always open the Tools Tab or click Create Restore Point. Fist Tool will automatically create an elevated Windows snapshot allowing 1-click rollback at any time.

CHAPTER 02

Step 2: GameLoop 120 FPS Setup

Navigate to the GameLoop Tab and follow these recommendations:

  • Renderer: Select DirectX+ (or OpenGL+ for AMD GPUs).
  • Memory: Allocate half your physical RAM (e.g., 8192 MB for a 16GB PC).
  • CPU Cores: Assign all physical performance cores (e.g. 6 or 8 Cores).
  • Click Apply to GameLoop to write the optimized settings.
CHAPTER 03

Step 3: TVM Keymapping Backup

GameLoop updates frequently wipe custom keybinds. Go to Tools Tab → Card 4 and click Backup TVM Keymapping. If your keys ever stop responding, click Restore TVM Keymapping to fix them instantly without re-binding in-game.

CHAPTER 04

Step 4: Windows Latency Tweaks

In the Tweaks Tab, select the Windows, CPU, GPU, and Network sub-tabs. Select the tweaks recommended for your hardware tier and click Apply Selected.
