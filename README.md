## ⚡ Key Features

### 🎮 GameLoop & PUBG Mobile Engine Manager
- **Direct Engine Settings:** Switch rendering engines (DirectX+ / OpenGL+), fast rendering cache, and discrete GPU prioritization (`GpuPreference=2;`).
- **Real-Time Latency & Priority Optimizer:** Zero-delay touch latency, SurfaceFlinger optimizations, FIFO UI threading, and 90 / 120 FPS unlock props.
- **PUBG Mobile File Management:**
  - One-click Backup & Restore for `Active.sav`.
  - Resource `Paks` folder synchronization.
  - Shader & Log cache cleanup.
  - OBB file installer & custom APK installer with live ASCII progress feedback.
  - **TVM Keymapping Manager:** Dedicated Backup & Restore for GameLoop keybindings (`%APPDATA%\AndroidTbox\TVM_100.xml`).
- **Complete GameLoop Uninstaller:** Safely terminates processes, removes background services (`QMEmulatorService`, `aow_drv`, `TGuard`), cleans registry trees, and wipes leftover temp directories.

### 🖥️ Windows & System Performance Suite (130+ Tweaks)
- **Dynamic Hardware Filtering:** Automatically tailors tweak availability based on your detected CPU (Intel / AMD), GPU (NVIDIA / AMD / Intel), and installed RAM capacity.
- **Windows Graphics Settings:** Hardware-Accelerated GPU Scheduling (HAGS), Variable Refresh Rate (VRR), Multiplane Overlay (MPO) disable, and Flip Model windowed game optimizations.
- **Network & Low-Latency Tuning:** Optimized TCP window auto-tuning, Nagle's algorithm disable, MTU discovery, and DNS flushing.

### 📊 Live Diagnostic Dashboard & Customization
- **Hardware Telemetry:** Real-time gauges for CPU utilization, GPU metrics, and RAM usage.
- **Glassmorphic Modern UI:** Dark aesthetic with customizable accent color presets (Red, Cyan, Neon Blue, Emerald, Purple, Gold, Orange, Magenta).
- **Discord Rich Presence (RPC):** Shows live optimizer status and in-game performance presence.
